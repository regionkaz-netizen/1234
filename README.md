## WAKASI Video Studio

Premium New Year 2026–2027 Instagram Reels, 15 seconds, vertical 1080 × 1920, 30 fps. Animated titles in navy and gold.

Run locally with Node.js:

```bash
npm install
npm run dev
npm run render
```

Rendered video: `out/wakasi-new-year-reel.mp4`. The project currently contains animated typography; background footage, voice and music can be added later.
